# Задание 6. Проверка планарности графа

В этой работе реализованы простой неориентированный граф, проверка его
планарности и визуализация планарных графов.

## Представление графа

Граф задается классом `Graph`. Внутри для каждой вершины хранится множество
ее соседей. Поэтому граф является неориентированным, а каждое ребро хранится
только один раз.

Петли и повторяющиеся ребра запрещены. При попытке добавить такое ребро
программа сообщает об ошибке.

## Проверка планарности

Для проверки используется теорема Куратовского. Согласно этой теореме,
граф непланарен тогда и только тогда, когда в нем есть подразделение графа
`K5` или `K3,3`.

В программе перебираются возможные вершины ветвления и простые пути между
ними. Внутренние вершины выбранных путей не должны повторяться. Если удается
найти нужный набор путей, найдено подразделение `K5` или `K3,3`, поэтому граф
считается непланарным.

Такой перебор подходит для небольших графов и хорошо показывает саму идею
алгоритма, но для больших графов работает медленно. Сейчас для одной
связной компоненты установлено ограничение в 12 вершин. Если граф больше,
функция `is_planar` выдает ошибку, а не делает непроверенный вывод.

## Визуализация

Простое расположение всех вершин по окружности не подходит: у планарного
графа при таком расположении могут появиться пересечения ребер. Поэтому для
визуализации выполняются следующие действия:

1. Перебираются циклические порядки соседей у вершин, пока не будет найдено
	планарное вложение.
2. По найденному вложению определяются грани графа и выбирается внешняя
	грань.
3. Вершины внешней грани располагаются по окружности.
4. Координаты остальных вершин вычисляются методом усреднения координат их
	соседей.
5. Перед рисованием проверяются пары ребер, не имеющих общей вершины. Если
	такие ребра пересекаются, расположение отклоняется.

Для построения рисунков используется библиотека Matplotlib.

## Запуск

Запускать программу нужно из корневой папки репозитория:

```bash
python task6/task6.py
```

В демонстрации проверяются простой планарный граф, граф куба, октаэдральный
граф и полный граф `K5`. Для планарных примеров сохраняются файлы:

- `planar_graph.png`;
- `cube_graph.png`;
- `octahedral_graph.png`.

`K5` распознается как непланарный и не визуализируется.
